# fake-news-detection
Fake news detection using Machine Learning (TF-IDF + Logistic Regression) on the ISOT dataset, built in Google Colab.
# Fake News Detection

## About the Project
Fake news ante internet lo, social media lo vache tappudu leda misleading news. 
Ee project lo news article real aa fake aa ani Machine Learning tho 
detect chestam.

## Dataset
ISOT Fake News Dataset use chesanu. Dantlo real news and fake news 
articles untayi.

## Methodology
1. Data load chesi clean cheyyadam (unnecessary words, symbols teeseyadam)
2. TF-IDF tho text ni numbers ga marchadam
3. Logistic Regression model train cheyyadam
4. Model accuracy check cheyyadam

## Tools Used
- Python
- Google Colab
- Pandas, NumPy
- Scikit-learn

## How to Run
1. `.ipynb` file ni Google Colab lo open cheyyandi
2. ISOT dataset download chesi Colab lo upload cheyyandi
3. Anni cells ni order lo run cheyyandi
